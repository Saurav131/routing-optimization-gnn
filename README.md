# GNN-Based Routing Optimization

This repository contains the implementation of a Graph Neural Network (GNN) framework for learning routing policies in communication networks. The objective is to approximate optimization-based routing solutions and enable fast inference for real-time traffic engineering scenarios.

## Overview

Traditional routing optimization methods such as Mixed Integer Linear Programming (MILP) can produce high-quality routing decisions but become computationally expensive as network size and traffic demand increase. This project explores the use of Graph Neural Networks as surrogate models that learn routing policies directly from optimization-generated solutions.

The framework was developed as part of research conducted under the National Supercomputing Mission (NSM) at C-DAC.

---

## Dataset Generation

Training data is generated by solving routing optimization problems on network topologies under varying traffic conditions.

Each sample consists of:

- Network topology represented as a graph
- Link capacities and utilization statistics
- Source and destination node pairs
- Traffic demand information
- Optimal routing paths generated using MILP

The optimization solutions serve as ground-truth labels for supervised learning.

---

## Data Preprocessing

The routing problem is represented as a graph where:

### Node Features

- Node degree
- Traffic statistics
- Topological information

### Edge Features

- Available bandwidth
- Current utilization
- Link capacity
- Congestion metrics

### Labels

For each routing request, the optimal path computed by the optimization solver is converted into edge-level routing decisions that can be learned by the GNN.

The dataset is then transformed into a format compatible with PyTorch Geometric.

---

## MILP-Based Routing Formulation

Ground-truth routing paths are generated using a Mixed Integer Linear Programming formulation.

### Objective

Optimize network utilization by minimizing congestion while satisfying traffic demands.

### Constraints

- Flow conservation
- Link capacity constraints
- Source-destination connectivity
- Valid path construction

MILP solutions provide optimal routing decisions that are used as supervision targets for the neural network.

---

## Graph Neural Network Models

The repository contains multiple message-passing architectures including:

### NNConv

Neural Message Passing framework where edge features dynamically parameterize message functions.

### GCN

Graph Convolutional Networks for topology-aware feature propagation.

### GAT

Graph Attention Networks that learn importance weights between neighboring nodes.

### MLP Baseline

A non-graph baseline for comparison.

---

## Training Pipeline

1. Generate routing solutions using MILP.
2. Construct graph representations.
3. Extract node and edge features.
4. Train GNN models on optimization-generated labels.
5. Evaluate route prediction accuracy and path reconstruction performance.

---

## Evaluation Metrics

- Exact Route Match Accuracy
- Edge Prediction Accuracy
- Path Reconstruction Accuracy
- Inference Time
- Comparison against MILP solutions

---

## Results

The message-passing GNN models successfully learn routing policies from optimization-generated data and achieve high route prediction accuracy while reducing inference time by several orders of magnitude compared to solving routing optimization problems online.
